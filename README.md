# Lip Blushing Delhi — Plain React + Vite

A standalone React 18 + Vite + Tailwind CSS version of the landing page.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Output goes to `dist/`. Deploy to Vercel, Netlify, Cloudflare Pages, or any static host.

## Stack
- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Framer Motion
- Lucide React icons
