# Lip Blushing Delhi — Plain React + Vite

A standalone React 18 + Vite + Tailwind CSS version of the landing page.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
vercel output link :- https://landing-page-react-eight-drab.vercel.app/

## Stack
- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- Framer Motion
- Lucide React icons
